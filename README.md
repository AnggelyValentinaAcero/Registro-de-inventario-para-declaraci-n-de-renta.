# Registro de inventario para declaración de renta. 


Este proyecto consiste en el desarrollo de una aplicación de software orientada a la gestión de inventarios con fines de apoyar el proceso de declaración de renta en Colombia.
La aplicación busca organizar la información relacionada con los productos, movimientos de inventario, métodos de costeo y reportes necesarios para el cierre del periodo fiscal.

----

## Objetivo

Identificar, organizar y gestionar la información necesaria para el desarrollo de una aplicación de inventarios que apoye el proceso de declaración de renta en Colombia.

---

## Funcionalidades

- Gestión de productos y categorías.
- Registro de movimientos de inventario, incluyendo entradas y salidas.
- Cálculo del costo de ventas mediante PEPS o promedio ponderado.
- Generación de reportes de cierre del periodo fiscal.
- Gestión de documentos soporte relacionados con los movimientos de inventario.
